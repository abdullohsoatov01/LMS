# Maktab AI — LMS для школьников

Платформа, где школьники изучают искусственный интеллект и промпт-инжиниринг. Интерфейс и уроки на узбекском языке.

**Для учеников:**
- 2 курса по 6 уроков: «Sun'iy intellekt nima?» и «Prompt muhandisligi»
- задания разных типов: квизы, расстановка по порядку, сортировка по группам и задачи на Python прямо в браузере (ничего устанавливать не нужно)
- игровые элементы: XP, уровни, значки, серия дней подряд, рейтинг класса, звёзды за уроки, выбор аватара
- уроки открываются по очереди

**Для учителя:**
- классы, массовое добавление учеников (логины и пароли генерируются автоматически, карточки можно распечатать)
- таблица прогресса по каждому уроку, сброс пароля, удаление учеников
- можно пройти любой урок глазами ученика (результат не сохраняется)

Технологии: Next.js 15, Supabase (только база данных), Tailwind, Pyodide (Python в браузере).

## Запуск в интернете (бесплатно, ~20 минут)

### 1. База данных — Supabase
1. Зарегистрируйтесь на https://supabase.com и создайте новый проект (New project). Регион подойдёт любой, ближайший — Frankfurt.
2. Откройте **SQL Editor → New query**, вставьте всё содержимое файла [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
3. Откройте **Project Settings → API** и скопируйте:
   - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`;
   - ключ **service_role** (или **secret key**) → это `SUPABASE_SERVICE_ROLE_KEY`. Этот ключ секретный, никому его не показывайте.

> На бесплатном тарифе Supabase ставит проект на паузу, если им не пользоваться 7 дней. Если так случилось, зайдите в панель Supabase и нажмите **Restore**.

### 2. Хостинг — Vercel
1. Загрузите эту папку в репозиторий на GitHub (можно приватный).
2. На https://vercel.com нажмите **Add New → Project** и выберите репозиторий.
3. В разделе **Environment Variables** добавьте переменные:

| Переменная | Значение |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role ключ из Supabase |
| `TEACHER_SIGNUP_CODE` | придумайте код: без него нельзя зарегистрировать учителя |
| `SESSION_SECRET` | любая длинная случайная строка (30+ символов) |
| `APP_TIMEZONE` | `Asia/Tashkent` (нужен для подсчёта серии дней) |

4. Нажмите **Deploy**. Через пару минут сайт будет доступен по адресу вида `https://ваш-проект.vercel.app`.

### 3. Первый вход
1. Откройте `https://ваш-сайт/setup` и создайте аккаунт учителя, указав `TEACHER_SIGNUP_CODE`.
2. Создайте класс и вставьте список учеников, по одному «Имя Фамилия» на строку.
3. Нажмите **Chop etish** («Печать») и раздайте ученикам карточки с логинами и паролями. **Пароли показываются только один раз.** Если ученик забыл пароль, нажмите 🔑 рядом с ним, чтобы создать новый.

## Как добавлять уроки (для вашей методики)

Все уроки хранятся в обычных файлах:
- [`src/content/courses/ai-asoslari.ts`](src/content/courses/ai-asoslari.ts)
- [`src/content/courses/prompt-muhandisligi.ts`](src/content/courses/prompt-muhandisligi.ts)

Урок состоит из шагов (`steps`). Доступные типы шагов:

| Тип | Что это |
|---|---|
| `text` | Теоретическая карточка: эмодзи, заголовок и текст в Markdown (**жирный**, списки, таблицы, цитаты `>`) |
| `quiz` | Вопрос с вариантами ответа. `correct: 1` — один правильный ответ, `correct: [0, 2]` — несколько |
| `order` | Расставить пункты по порядку. В файле пункты пишутся в правильном порядке, ученику они показываются перемешанными |
| `classify` | Разложить карточки по 2–4 группам |
| `code` | Задача на Python: стартовый код, тесты (`assert`), эталонное решение и подсказка |

Новый курс: создайте файл в `src/content/courses/` по образцу существующих и добавьте его в список `COURSES` в [`src/content/index.ts`](src/content/index.ts). Значок за прохождение курса появится автоматически.

**Важно:** не меняйте `id` уже опубликованных уроков и курсов, иначе прогресс учеников по ним потеряется.

XP: +10 за каждое задание, решённое с первой попытки, и +20 за завершение урока. При повторном прохождении начисляется только разница, если результат стал лучше.

## Безопасность
- Пароли хранятся в виде хешей (scrypt). Сессия хранится в подписанной cookie (HttpOnly).
- К базе данных обращается только сервер с секретным ключом. Из браузера доступа к таблицам нет (RLS включён без политик).
- У учеников нет email, логины выдаёт учитель.
